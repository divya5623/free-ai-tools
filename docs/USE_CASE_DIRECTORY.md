# Practical Free Tools Directory

A practical reference for developers, AI builders, students, and startups. Each entry includes an official link, why it is useful, and when to use it.

> **Important:** Free plans, quotas, commercial-use terms, and eligibility can change. Always verify the provider's current terms before production use.

## Access labels

- 🟢 **Open Source / Self-hosted:** The software is available to run independently; infrastructure may cost money.
- 🔵 **Free Tier:** A provider offers free usage with limits.
- 🟡 **Free for Learning / Conditional:** Access may depend on eligibility, credits, or restrictions.
