# Project Roadmap

## Current Focus

- Maintain a clear, professional resource taxonomy.
- Add official pricing and documentation links.
- Record free-tier limits with verification dates.
- Improve searchability and consistency across categories.

## Planned Improvements

- [ ] Split large categories into dedicated Markdown files.
- [ ] Add a consistent resource metadata template.
- [ ] Add automated link checking through GitHub Actions.
- [ ] Add a structured JSON catalog for future search or website integration.
- [ ] Add filters for open source, free tier, student access, and self-hosted tools.
- [ ] Introduce a changelog for major catalog updates.
- [ ] Review stale pricing and quota information periodically.

## Quality Goal

Build a trustworthy, maintainable, and useful reference that developers, students, educators, and technical reviewers can navigate quickly.
