# Security Policy

## Scope

This repository is a curated directory of public tools and resources. It does not request or store API keys, passwords, access tokens, or other private credentials.

## Reporting a Security Concern

If you identify a security issue in repository content, a malicious link, exposed secret, or unsafe recommendation:

1. Do not publish sensitive information in an issue.
2. Contact the maintainer privately through GitHub.
3. Include the affected file or link, impact, and suggested remediation.

Never commit API keys, tokens, passwords, personal data, or private configuration files.
