# Contributing Guide

Thank you for helping improve **Free AI Tools & Developer Resources**.

## Contribution Principles

We value accuracy, clarity, accessibility, and maintainability. Contributions should help readers make informed decisions about tools, pricing, licensing, and usage restrictions.

## Before Opening a Pull Request

- Verify the resource using its official website or documentation.
- Prefer official links over referral or affiliate links.
- Clearly identify whether the resource is open source, free tier, credit-based, or paid after an allowance.
- Do not describe a service as “unlimited free” without an explicit official guarantee.
- Include known quotas, restrictions, expiry conditions, or eligibility requirements.
- Add a verification date when documenting changing pricing or limits.
- Use concise, professional language.

## Recommended Entry Format

```markdown
| Tool | Official link | Purpose / use case | Free status & verified limit | Last verified |
|---|---|---|---|---|
| Example | https://example.com | Short practical description | 🔵 Free tier; check official quota | YYYY-MM-DD |
```

## Pull Request Checklist

- [ ] The official link works.
- [ ] The description is factual and concise.
- [ ] Free or paid status is clearly identified.
- [ ] Usage limits are not invented.
- [ ] Licensing or eligibility restrictions are mentioned when relevant.
- [ ] Markdown formatting is readable.
- [ ] The change does not include secrets, tokens, or private data.

## Reporting Incorrect Information

Open an issue with the resource name, the incorrect information, the official source, and the suggested correction.
